# UML & Architecture Diagrams Rule

When asked to design, visualize, or explain architectural components, workflows, or data models:
- Generate clean, standard PlantUML (`@startuml ... @enduml`) or Mermaid (`mermaid`) diagrams.
- For PlantUML:
  - Sequence diagrams: Show interactions, actors, service calls, and responses.
  - Class / Entity diagrams: Show classes, interfaces, attributes, and relationships.
  - Component / Architecture diagrams: Show modules, layers, and external dependencies.
- Utilize the `plantuml` MCP server tools to render or validate diagrams when necessary.
